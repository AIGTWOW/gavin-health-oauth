Privacy Policy

Last updated: 17 September 2026

This privacy policy describes how the Personal Health Integration application ("the application") accesses, uses and stores data obtained through the Google Health API.

1. Who operates this application

The application is developed and operated by a single individual for their own personal use. It is not a commercial product and is not available to the general public. Only the developer's own Google account can authorise access.

2. What data the application accesses

With the account owner's explicit consent, the application requests read-only access to the following categories of the owner's own Google Health data:

ScopeData accessed
ProfileBasic profile information associated with the health account
SettingsUnit and timezone preferences needed to display data correctly
Activity & fitnessSteps, distance, calories, exercise sessions
Health metrics & measurementsHeart rate, resting heart rate, heart-rate variability, body measurements
SleepSleep sessions, sleep stages, nightly skin-temperature variation
NutritionLogged food and hydration entries, if any

All access is read-only. The application cannot create, modify or delete any data in the Google Health account.

3. How the data is used

Data is used solely to produce the owner's own personal health summaries — for example, correlating sleep quality with resting heart rate and training load. No automated decision-making affecting any person is performed, and no profiling for advertising purposes takes place.

4. How the data is stored

  • Data is stored on the developer's own private server, protected by operating-system access controls.
  • Authentication tokens are stored in a restricted file readable only by the server's system account.
  • No data is stored in any public cloud service, and no third-party analytics or tracking scripts are used on this site.

5. Data sharing and disclosure

Data obtained through the Google Health API is never sold, rented, traded, published, or shared with any third party. It is not used for advertising, marketing, credit assessment, insurance assessment, or training of machine-learning models.

6. Google API Services User Data Policy compliance

The application's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

7. Data retention and deletion

The account owner may revoke the application's access at any time at myaccount.google.com/permissions. Revoking access immediately invalidates the stored authentication tokens. Locally stored derived summaries can be deleted by the owner from their own server at any time. No copy of the data is retained anywhere else.

8. Security

Access tokens are stored with restricted file permissions. Communication with Google APIs takes place exclusively over HTTPS. The server is kept up to date with security patches.

9. Children's privacy

The application is used by a single adult account owner and is not directed at children.

10. Changes to this policy

Any change to this policy will be published on this page with an updated revision date.
